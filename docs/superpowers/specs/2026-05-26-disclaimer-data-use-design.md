# 免责声明与数据使用说明更新设计

## 目标

将现有仅覆盖申请结果与信息准确性的免责声明，更新为面向家长和学生可读的“免责声明与数据使用说明”。页面应准确覆盖当前产品已经存在的 AI 生成、账户登录、学生规划存储、行为统计和资料推荐功能，不宣称超出现有实现的数据能力或合规承诺。

## 当前缺口

现有页面已说明信息参考性质、无录取承诺、学校政策变化、材料诚信和 GPA/选课差异，但未清晰告知：

- 规划生成会通过 OpenAI API 使用第三方 AI 模型服务，输出可能存在遗漏、误解或过期信息；
- 竞赛、夏校、科研、院校百科和相似案例内容不是官方推荐或报名资格确认；
- 系统保存注册邮箱、密码安全校验信息、会话、密码重置记录，以及登录时间、浏览器/IP 等安全记录；
- 系统保存学生档案、规划草稿和历史快照，并记录部分功能使用事件；
- 学生材料可能涉及未成年人及教育背景信息，提交前需要家长/监护人知情并避免上传不必要敏感材料；
- 用户需要一个联系渠道以咨询更正或删除已保存内容。

## 页面方案

保留单一入口 `disclaimer.html`，将标题改为“免责声明与数据使用说明”，避免拆出未接通的独立隐私政策页。正文结构为：

1. 服务性质与不保证结果。
2. AI 辅助生成与人工核验。
3. 信息来源、项目推荐与案例非背书。
4. 用户输入、申请材料诚信以及 GPA/选课规则差异。
5. 账户、安全与使用记录。
6. 学生档案、规划版本与未成年人信息。
7. 第三方政策变化、责任边界及联系渠道。

文案只描述代码中实际可证实的数据范围，不承诺特定保存期限、数据导出能力、自动删除能力或法规意义上的完整隐私政策。

## 验证

新增页面内容测试，要求标题及 AI、资源核验、账户记录、学生档案/未成年人、联系删除等关键告知均存在。运行项目 `npm test` 与 `npm run check`，并在已知本地页面可访问时检查免责声明页面呈现。
