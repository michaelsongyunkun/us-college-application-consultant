# 可信平衡型品牌首页与工作台 UI 设计规格

**日期：** 2026-05-26  
**状态：** 已确认视觉方向，待用户审阅书面规格  
**范围：** 公开入口首页、认证卡片、登录后规划工作台，以及资源库与院校百科的共享视觉语言

## 目标

借鉴 COR SeniorFriend 的设计亮点，将当前以工具为主的界面升级为兼顾亲和力、专业度与可信度的产品体验：

- 未登录访客能够在首屏理解产品价值，并直接登录或免费注册。
- 已登录用户继续使用现有规划 Agent、资源库和院校百科能力，但在更清晰、温和、统一的界面中完成任务。
- 用明确的信任表述解释资料来源与产品边界，不夸大录取结果或替代官方政策。

本次改版只调整 UI 呈现，不删除或替换网站原有功能与数据库。本轮不修改 Agent 提示词、推荐算法、用户资料结构、报告保存与导出内容，也不开放当前受登录保护的工具数据。

## 已选方向

采用 **C：可信平衡型**。

该方向融合 COR 式的温暖首屏与真人服务产品常见的低压转化方式，同时保留本项目作为规划工具的专业感：

- 背景使用暖白色，减少原有工具界面的冷硬感。
- 正文与标题使用深蓝色，保持理性与可信气质。
- 绿色强调“适合你”“可信资料”“真实信息”等价值表达。
- 橙色仅突出关键转化按钮，如“免费开始规划”和登录/注册提交。
- 卡片使用轻边框、较大圆角和有限阴影，形成开放、轻量的阅读节奏。

## 信息架构

### 未登录公开首页

`index.html` 在未登录状态下由原先的居中登录卡升级为完整公开首页，包含以下区块：

1. **品牌导航**
   - 品牌名称建议为 `US College Compass`，作为当前中文产品名的视觉品牌标识。
   - 导航展示产品能力锚点或说明入口：规划方式、资源与院校、可信承诺、关于我们。
   - 右侧保留显著的登录/免费注册入口语义。

2. **首屏 Hero**
   - 标题采用问题式表达：`你的申请路径，真的适合你吗？`
   - 副文案说明价值：根据学生背景、兴趣方向与院校资料，形成清晰且可执行的规划建议。
   - 左侧提供主行动按钮 `免费开始规划`，点击后将焦点引导到右侧现有认证表单。
   - 右侧嵌入现有登录/注册/找回密码表单，继续复用已有提交、错误状态与重置密码流程。

3. **能力背书条**
   - 用三项非虚构的能力描述替代不可靠的数据宣称：
     - `个性规划`：围绕学生背景生成
     - `可信资料`：保留来源与适用边界
     - `规划报告`：支持保存与导出

4. **核心能力卡片**
   - `规划 Agent`：从背景信息生成活动与成长方向。
   - `资源与院校`：登录后查看资源库和院校百科。
   - `可信承诺`：提示建议不等于录取承诺，官方最新要求为准。

5. **使用流程**
   - 三步结构：填写背景、生成方案、保存并对照资料。
   - 使用带编号的横向卡片，与登录后的工作台引导保持一致。

6. **家长与信任模块**
   - 面向家长说明：规划建议强调可核对、可保存、可复盘。
   - 展示资料来源提示、隐私与不夸大承诺等原则。

### 登录后规划工作台

登录成功后继续显示当前工作台及已有业务模块，信息结构不重排为新流程，只做统一视觉与层级强化：

- 页眉使用与公开首页相同的品牌、颜色与导航风格。
- “三步完成申请规划”继续作为首要引导模块，改为浅暖色重点卡片。
- 学生摘要、当前方案、历史备份卡片采用更轻的边框与更舒展的内间距。
- 主按钮仅用于生成、保存等正向核心任务；导出、退出继续为次级操作；清空与删除保持危险语义。
- 长内容输出、推荐和匹配卡片统一标题、标签、状态提示与空状态层级。

### 资源库与院校百科

两个受保护页面不新增公开数据预览，只同步共享外观：

- 加入统一品牌页眉和返回规划工作台的明确入口。
- 沿用绿色/橙色/深蓝的强调规则以及卡片圆角、边框和留白。
- 保持现有搜索、筛选、分页加载、详情展开和资料免责声明行为不变。

## 组件与实现边界

### 功能与数据库保护边界

- 保留当前已经存在的登录、注册、找回密码、规划生成、方案与历史备份、资源库、院校百科、GPA 计算器、选课辅助器、免责声明、联系我们、管理看板以及 JSON/Word 导出功能。
- 保留当前认证数据库、用户数据、规划数据、分析记录与本地资料文件；不得删除、迁移、清空、重建或更换任何数据库表和存储路径。
- 本轮不修改 `server.mjs`、`auth-db.mjs`、`auth-service.mjs`、`planning-service.mjs`、`draft-storage.mjs` 以及 `data/` 中的业务数据内容。
- 实施允许修改 HTML/CSS 的结构与样式，以及在 `app.js` 中增加仅用于页面展示和聚焦认证入口的最小 UI 行为；不得移除现有事件绑定、接口请求、字段 `id` 或已存在的页面跳转能力。
- 如果 UI 目标与保留原有功能发生冲突，以保留功能和数据为优先，收缩视觉改动范围。

### 复用现有功能

- 认证表单的元素 `id` 和 `app.js` 中的登录、注册、找回密码、重置密码、登录态检查逻辑保持兼容。
- `appShell` 登录后的业务区域、现有表单字段、结果元素及事件绑定的 `id` 不变。
- 资源库与院校百科的数据读取、筛选和分页逻辑不改变。

### 需要新增或调整的呈现结构

- `index.html`：将 `authShell` 变为公开品牌首页容器，在 Hero 中承载现有 `authForm`；增加价值、能力、流程与信任模块。
- `styles.css`：更新设计 token，并加入公开首页、品牌页眉、Hero、能力卡片、流程卡片与信任模块样式；同步既有工作台和工具页视觉。
- `resource-library.html`、`school-encyclopedia.html`：在不影响原有功能的前提下应用统一品牌页眉 class 与说明层级。本轮不修改 GPA、选课、联系或免责声明页面的专属布局。
- `app.js`：仅在需要将 Hero 主按钮聚焦到认证卡片、或登录/退出切换公开页面状态时添加最小交互；认证与规划数据逻辑不改写。

## 内容与语气

- 主标题面向学生和家长共同决策，避免焦虑营销。
- 页面使用“规划建议”“参考资料”“官方最新要求为准”等严谨用语。
- 不展示未有数据来源支撑的学生数量、录取率、覆盖学校数量或满意度。
- 如果需要展示能力背书，以已存在的功能事实描述，而不是伪造统计数字。

## 响应式与可访问性

- 桌面首屏使用左侧价值主张、右侧认证卡片的双栏布局。
- 小屏设备将认证卡片排在 Hero 文案与主按钮之后，确保注册/登录无需长距离滚动。
- 导航在窄屏允许换行或折叠为紧凑操作区，保持主行动可触达。
- 表单保持可见标签、状态提示与键盘可操作性；颜色不能成为区分危险操作与普通操作的唯一信号。
- 现有 `aria-live` 状态区域与安全导航行为继续保留。

## 状态与错误处理

- 未登录状态显示完整品牌首页和认证卡片。
- 登录或注册成功后切换至现有工作台，不保留遮挡工作内容的营销模块。
- 退出登录后返回公开首页，并在认证卡片中显示退出完成提示。
- 登录错误、注册错误、找回密码结果及重置密码状态继续在认证卡片内部反馈。
- 工具页数据加载失败、无结果或仍有更多内容时，沿用现有状态逻辑并更新视觉呈现，不改变判断规则。

## 测试与验收

自动化结构测试应覆盖：

- 未登录入口具有品牌 Hero、认证卡片容器、核心能力、流程与可信承诺模块。
- 现有认证表单关键 `id` 及登录后工作台关键 `id` 均被保留。
- 首屏主按钮具有聚焦认证入口的可访问行为。
- 共享样式包含新品牌 token、公开首页布局和移动端布局规则。
- 工具页继续保留搜索、筛选、分页加载、资料来源说明和返回工作台入口。
- 现有认证、规划保存、工具数据访问和导出相关测试继续通过，证明 UI 变更未删除功能或改动数据库行为。

浏览器验收应覆盖：

- 桌面宽度下首页首屏的双栏层级、主按钮与认证卡片可读性。
- 手机宽度下 Hero、认证卡片、流程卡片与导航不会溢出。
- 登录、注册、找回密码、退出登录仍能在新的公开入口中完成。
- 登录后的规划工作台、资源库与院校百科在统一视觉中仍可正常操作。

## 不包含内容

- 不将资源库或院校百科改为未登录可访问。
- 不添加真实学长学姐、录取案例评价或无事实依据的平台统计。
- 不修改 Agent 的提示词、生成服务、推荐算法或报告字段。
- 不删除、重建或迁移数据库，也不删除任何现有用户功能、页面入口或导出能力。
- 不改版 GPA 计算器、选课辅助器、联系我们或免责声明页面的页面结构。
- 不进行后台管理页的功能重构；如共享样式自然覆盖其基础外观，可接受轻量同步。
