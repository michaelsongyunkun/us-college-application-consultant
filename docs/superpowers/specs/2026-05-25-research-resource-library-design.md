# 实习/科研库资料检索设计

## 目标

在现有“资源库”页面新增第三类资料库“实习/科研库”，将用户提供的
`科研项目清洗标注_Markdown格式.docx` 中的科研项目整理为可浏览、可搜索、
可按临时参与条件筛选的资源数据。

本次采用现有资料库架构：以可维护的 Markdown 文件保存项目资料，在浏览器
端解析并展示。这里的 RAG 首版定位为“可检索的知识资料库入口”，不加入
生成式回答或向量检索服务。

## 已确认范围

### 包含

- 资源库新增 `实习/科研库` 标签页。
- 将来源文档中的 21 个科研项目转换为本地 Markdown 数据集。
- 展示项目评级、项目形式、周期、费用、导师背景、报名条件、适合人群、
  产出与官网等来源字段。
- 复用资源库的关键词搜索框检索当前选中的实习/科研库。
- 复用资源库中已有的国籍、身份说明和参加方式临时筛选规则。

### 不包含

- 不将科研项目推荐接入首页规划 Agent。
- 不将科研项目写入规划报告或 Word 导出。
- 不新增问答框、模型调用、Embedding、向量库或服务端检索 API。
- 不凭空补充文档中不存在的实习项目；标签名预留未来实习数据扩展。
- 不验证来源文档中的费用、官网、项目评价或申请要求是否为最新信息。

## 数据来源与内容边界

来源文档当前包含 21 条科研项目数据：

- `A+` 档 2 条。
- `A` 档 9 条。
- `B+` 档 10 条。

文件内容未包含明确的实习项目。本次页面标签使用用户指定的
`实习/科研库`，首版列表展示的是科研项目；当未来取得实习项目资料时，可
沿用同一数据格式追加或扩展类型字段。

由于项目费用、项目可用性与资格可能变化，页面只展示来源数据，并沿用资源
库现有提示：资格判断以项目官网为准。

## 页面交互

资源库标签顺序为：

1. `竞赛库`
2. `夏校库`
3. `实习/科研库`

用户点击第三个标签后：

- 当前列表仅展示科研项目数据。
- 搜索框占位提示更新为检索科研项目的文案。
- 页面数量概览显示当前可查看项目数与数据总数。
- 已填写的临时可参与条件保持有效，并立即作用于科研项目列表。

项目卡片展示：

- 项目名称和评级。
- 项目形式、周期与费用。
- 导师背景。
- 报名条件。
- 适合人群。
- 产出。
- 官网链接。

简介信息纳入关键词检索范围，可不在卡片首屏完整展开，以避免卡片过长。

## 数据与解析架构

### 数据文件

新增 `data/research-projects.md`，保留原 Word 的 Markdown 化结构和字段文本。
数据文件由来源文档转换而来，后续可由维护人员直接编辑或追加项目。

### 解析模块

新增独立解析模块，例如 `research-project-recommender.mjs`，只负责将 Markdown
块转换为结构化项目数组。每条项目包含：

- `id`
- `name`
- `tier`
- `rating`
- `recommendation`
- `format`
- `duration`
- `cost`
- `mentorBackground`
- `description`
- `requirements`
- `suitableFor`
- `outputs`
- `website`

该模块不承担 AI 推荐逻辑；命名可与现有资料解析模块保持一致，未来再扩展
个性化推荐函数。

### 页面集成

`resource-library.js` 负责：

- 同时加载第三个 Markdown 数据文件。
- 调用解析器并接入现有资格元数据增强逻辑。
- 在激活实习/科研标签时执行关键词检索与条件筛选。
- 渲染科研项目卡片、数量、空状态与已排除原因。

现有竞赛库和夏校库行为保持不变。

## 检索与筛选规则

关键词搜索覆盖以下字段：

- 项目名称、评级档位、项目形式。
- 导师背景、简介、报名条件、适合人群、产出。

可参与条件筛选沿用现有保守判断：

- `项目形式`明确为线上、线下或混合时，可与`参加方式`筛选匹配。
- 文档明确写出接受国际生或身份限制时，才产生相应资格判断。
- 文档没有明确资格结论时，项目继续保留并显示`资格待核实`，不误排除。

## 异常与空状态

- 新数据文件读取失败时，第三个标签页显示“暂时无法读取实习/科研库”，
  竞赛库与夏校库仍可正常工作。
- 搜索或条件筛选后没有可查看项目时，显示清晰空状态，并保留明确被排除的
  项目及原因。
- 由于来源文档当前不包含实习项目，页面无需额外展示虚构的实习分类或
  占位项目。

## 测试与验收

实现应至少覆盖：

- 解析器从 Markdown 样本中正确提取字段，并能解析完整数据集为 21 条记录。
- 页面 HTML 存在 `实习/科研库` 标签和对应面板。
- 页面脚本载入第三个数据集，并按当前标签切换渲染。
- 搜索词可命中名称、方向或报名条件等科研项目字段。
- `线上`科研项目在用户选择`仅线下`时能被现有筛选规则排除。
- 缺少明确国际身份条件的科研项目不会被错误排除。
- 新数据集受既有登录保护的 `/data/` 静态路径规则覆盖。
- 运行现有测试与语法检查，并在本地页面中核查第三标签页浏览、搜索与筛选。
