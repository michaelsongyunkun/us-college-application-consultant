# 核心 UI 体验优化设计规格

**日期：** 2026-05-26  
**状态：** 已确认方案 A，待实施计划  
**范围：** 美本申请规划 Agent 前端核心入口、操作层级、登录反馈、资源库与院校百科浏览体验

## 目标

在不修改申请规划生成逻辑、推荐匹配规则、RAG 数据内容或报告导出数据结构的前提下，降低首页首屏操作噪音，统一按钮风险语义，并提高大规模资料列表在桌面端与移动端的阅读效率。

## 已选方案

本次采用“核心体验优化”方案：

- 导航优先呈现 `申请规划`、`资源库`、`院校百科` 三个核心入口，将 GPA、选课、免责声明、联系我们等辅助入口视觉降级。
- 将按钮分为主操作、普通辅助操作与危险操作三个明确层级。
- 登录状态提示仅在存在提示内容时展示，消除登录卡片中的空白提示条。
- 资源库与院校百科列表均默认分批展示，并提供继续加载入口，避免首屏直接呈现数百条内容。
- 保持现有筛选、详情展开、资料来源提示、规划结果与导出行为不变。

## 信息架构与页面行为

### 首页

首页顶部区域将区分主要导航与辅助入口。用户的首要路径为进入申请规划、资源库和院校百科；工具页与说明页仍可随时访问，但不与首要任务竞争视觉注意力。

操作按钮遵循以下语义：

- `保存当前内容` 保持为主要操作。
- `导出 JSON`、`导出 Word` 与 `退出` 使用普通辅助样式。
- `清空当前方案`、删除历史方案等会造成数据丢失的动作使用危险样式。

首页现有表单、规划结果、历史版本和 Agent 生成逻辑不在本次重排或改写范围内。

### 登录反馈

登录与注册卡片保留现有流程和提示文本。状态区域在无消息时不占用可见高度；出现加载、成功或错误消息时再按现有提示样式显示。

### 资源库

筛选字段、参加方式判断和当前三类资料内容保持不变。列表初始仅展示一批结果，并在仍有匹配项时显示“加载更多”。每次切换标签页、搜索或重新应用筛选时，显示数量重置为首批，结果状态同时说明当前已展示数量与总匹配数量。

非破坏性的“清除条件”使用普通辅助按钮样式，不再呈现为危险操作。

### 院校百科

学校检索、综合大学/文理学院分类与单校详情内容保持不变。每个分类的列表初始分批展示，搜索或切换分类后重新从首批开始；尚有匹配学校时提供“加载更多”。

页面保留资料来源与非官方招生结论提示，让分批浏览不会误导用户对内容完整性或时效性的判断。

## 组件与实现边界

本轮变更以现有静态页面结构和共享样式表为基础，不引入前端框架或新的后端接口：

- `styles.css` 承担导航层级、按钮语义、登录空状态及加载更多区域的共享视觉规则。
- `index.html` 调整顶部入口和按钮 class，不改变表单字段或业务元素的 id。
- `resource-library.html` 与 `resource-library.js` 增加列表分批展示控制，并调整非危险按钮语义。
- `school-encyclopedia.html` 与 `school-encyclopedia.js` 增加列表分批展示控制。
- 测试文件校验关键结构与列表分页/重置行为，避免未来改动恢复信息过载或混淆操作风险。

## 数据流与异常处理

资源库和院校百科仍先读取现有本地 Markdown/RAG 数据，再执行已有搜索或筛选。分批展示只作用于过滤后的前端结果数组，不改变原始数据、检索匹配、详情内容或数据加载失败提示。

若数据加载失败，页面沿用现有错误状态，不展示无效的加载更多操作。若筛选后没有匹配结果，数量提示与空状态优先于加载控件。

## 响应式与可访问性

- 小屏幕上核心导航保持可读、可触达，辅助入口不挤压主要操作。
- “加载更多”必须使用可键盘访问的按钮，并随结果剩余量正确隐藏。
- 状态提示与结果计数继续通过现有可感知文本向用户说明当前页面状态。
- 按钮颜色与文字含义一致，危险色只用于可能丢失数据的动作。

## 测试与验收

实现采用测试先行方式，至少覆盖：

- 登录状态区域在空内容时不显示的样式契约。
- 首页按钮与导航层级具备对应结构和语义 class。
- 资源库初始展示数量受限、加载更多会增加可见结果、筛选或标签切换会重置显示批次。
- 院校百科初始展示数量受限、加载更多会增加可见学校、搜索或分类切换会重置显示批次。
- 原有项目检查与测试命令继续通过。

浏览器验收覆盖桌面与手机宽度下：首页顶部操作层级、登录页空状态、资源库多结果浏览、院校百科搜索与展开详情。

## 不包含的内容

- 不重构首页为分步骤向导。
- 不修改申请规划提示词、生成服务、推荐逻辑、用户数据存储或导出格式。
- 不扩充或修订 RAG 文档中的院校、活动或项目内容。
- 不引入排序、收藏、对比或高级筛选等新的资料管理能力。
