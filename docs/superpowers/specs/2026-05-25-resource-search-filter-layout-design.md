# 资源库搜索框合并布局设计

## 目标

将资源库页面的`搜索当前资源库`输入框并入`我的可参与条件`区域，使资源检索与资格筛选集中在同一操作面板中。

## 范围

- 将现有搜索输入框移入可参与条件表单，和`国籍`、`身份说明`、`参加方式`并列展示。
- 下方工具栏仅保留`竞赛库`与`夏校库`标签切换。
- 保持搜索实时过滤当前分类的现有行为。
- 保持国籍、身份说明和参加方式在点击`应用筛选`后生效的现有行为。
- 手机宽度下，搜索及筛选字段采用单列布局，不产生横向溢出。

## 不包含

- 不新增或接入文书库。
- 不修改竞赛与夏校资格判断规则。
- 不修改搜索结果内容、数据来源或登录保护。

## 验收

- 页面上不再有独立于筛选面板之外的搜索输入框。
- 竞赛库与夏校库切换后，筛选面板中的搜索框仍能实时检索对应分类。
- 既有资格筛选、清除条件及已排除项目展示保持正常。
- 桌面与手机宽度布局均无明显挤压或横向溢出。
