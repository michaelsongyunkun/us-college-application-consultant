# 院校百科资料浏览页设计

## 目标

在美本申请规划 Agent 首页顶部辅助工具导航中，在`资源库`与`免责声明`
之间新增`院校百科`入口。登录用户点击后进入独立页面，检索并浏览来源
文档中的美国综合大学与文理学院介绍及申请要求。

本次将用户提供的
`综合_T80_文理TOP50_数据清洗_Markdown版.docx` 作为资料来源。首版对
RAG 资料库的使用定位为“可检索、可展开阅读的知识内容”，不增加 AI 问答、
模型调用或向量检索。

## 已确认范围

### 包含

- 在首页导航中增加`院校百科`按钮，位置固定在`资源库`与`免责声明`之间。
- 新建登录后可访问的独立`院校百科`页面。
- 页面展示来源文档中的综合大学与文理学院记录。
- 支持按院校类别切换，以及按学校名称、学校特色和申请要求等内容实时搜索。
- 使用院校卡片展示摘要，点击后展开完整申请资料。
- 页面注明资料来源，并提示政策与申请要求应以对应申请年度官网为准。

### 不包含

- 不增加 AI 问答输入框、生成式回答、Embedding 或向量数据库。
- 不为文档没有提供的信息补充官网链接、实时排名、录取率或申请政策。
- 不修改或回写用户提供的原始 DOCX。
- 不将院校百科内容接入首页 Agent 报告生成或 Word 导出。

## 数据来源与数量边界

来源 DOCX 已整理为 Markdown 风格段落结构，包含两个院校类别及四项稳定字段：

- `综合性大学 T80（原文标注：67 所）`
- `文理学院 TOP 50（原文标注：50 所）`
- `申请与文书`
- `学校特色`
- `录取偏好`
- `推荐信要求`

实际逐条解析到的院校标题记录为 `118` 条，其中综合大学部分有 `65` 条、
文理学院部分有 `53` 条。两者均与章节标题中的原文标注数量存在差异。页面
应忠实展示来源数据的全部记录，并在数量显示和来源说明中保留此事实，不擅自
删除并列排名记录或用未提供的资料补齐名义数量。

## 页面导航与保护

首页的辅助工具顺序调整为：

1. `GPA计算器`
2. `选课辅助器`
3. `资源库`
4. `院校百科`
5. `免责声明`
6. `联系我们`

新页面遵循已有辅助页面结构：

- 顶部显示英文 eyebrow 与中文页面标题。
- 操作区提供`返回规划 Agent`和`资源库`链接。
- 链接沿用 `data-safe-nav` 防重复导航行为。
- `school-encyclopedia.html` 和其数据文件由现有服务端登录保护规则覆盖；
  未登录直接请求应返回 `401`。

## 页面体验

### 页头与来源提示

页面标题使用`院校百科`，主体介绍为`美国院校介绍与申请要求`。标题区域
展示一条简洁说明：

- 资料来自用户提供的院校文档。
- 内容便于初步研究与申请规划。
- 文书题目、推荐信规则和其他政策会随申请年度变化，应以学校官网最新要求
  为准。

### 搜索与分类

页面顶部筛选区域提供：

- 一个搜索输入框，占位提示为`搜索学校中文名、英文名、特色或申请要求`。
- 两个分类标签：`综合大学 T80`和`文理学院 TOP50`。
- 当前分类的结果计数，例如`显示 67 / 67 所`。

默认选中`综合大学 T80`。搜索仅过滤当前分类，切换分类时保留搜索词并立即
渲染新分类中的匹配结果。

搜索覆盖字段：

- 排名文字与中文/英文校名。
- 申请与文书。
- 学校特色。
- 录取偏好。
- 推荐信要求。

### 卡片浏览与展开

院校以响应式卡片网格展示。默认折叠的每张卡片显示：

- 类别与排名。
- 中英文学校名称。
- `学校特色`的摘要文本。
- `展开详情`操作。

用户点击卡片操作后，该卡片展开并显示来源文档中的四个字段全文：

- `申请与文书`
- `学校特色`
- `录取偏好`
- `推荐信要求`

再次点击可收起。展开状态只存在于当前页面会话中，不保存到账户资料。
搜索无匹配项时，显示明确的空状态文案。

## 数据与模块架构

### 数据文件

新增 `data/schools.md`，以项目当前资料库采用的可维护 Markdown 数据模式
存储 DOCX 中转换出的院校内容。数据文件保留原文的类别标题、排名、学校名称
和四项字段文字，方便未来替换来源文档后重新维护或迁移至真正的 RAG 服务。

### 解析模块

新增 `school-encyclopedia.mjs`，职责仅限于将 Markdown 内容转为结构化数据，
以及提供与院校页面相关的轻量搜索函数。每条院校记录包含：

- `id`
- `category`：`university` 或 `liberal-arts`
- `categoryLabel`
- `rank`
- `name`
- `applicationAndEssays`
- `schoolFeatures`
- `admissionPreferences`
- `recommendationRequirements`

解析器不得补写资料内容或实时政策判断；遇到缺失字段时以空字符串保存，
由页面提供清晰的`来源资料未提供`展示。

### 页面脚本

新增 `school-encyclopedia.js`，负责：

- 加载 `./data/schools.md` 并调用解析模块。
- 按类别和搜索词过滤记录。
- 渲染结果数量、空状态和院校卡片。
- 管理卡片展开/收起及标签可访问状态。
- 在数据加载失败时展示`暂时无法读取院校资料库`状态，而非渲染虚构数据。

页面脚本不处理登录、AI 请求或数据写回。

### 样式

在现有 `styles.css` 增加仅服务于院校百科的布局类，复用当前资源库面板、
按钮、标签和卡片的视觉系统。桌面采用卡片网格，窄屏下切换为单列，并确保
展开字段在中文长文本下不产生横向溢出。

## 异常与内容责任

- 数据读取失败：页面保留结构与导航，状态文字说明资料暂不可用。
- 搜索无结果：显示`没有匹配的院校资料。`。
- 单条记录字段缺失：对应字段显示`来源资料未提供`，不推测内容。
- 页面不宣称资料为最新政策，始终显示官网复核提示。

## 测试与验收

实现至少覆盖：

- 解析器可从 Markdown 样本提取类别、排名、校名和四项字段。
- 完整数据文件解析得到 `118` 条学校记录，并覆盖综合大学和文理学院分类。
- 首页导航中的`院校百科`位于`资源库`与`免责声明`之间。
- 新页面包含搜索输入、两个类别标签、资料提示和卡片容器。
- 页面脚本会加载结构化数据并支持当前类别搜索与展开展示。
- 新页面在未登录请求时返回 `401`，登录后可读取页面及 `data/schools.md`。
- 运行项目的完整测试与语法检查。
- 在浏览器中验证导航、分类切换、关键词搜索、卡片展开/收起及移动宽度布局。
