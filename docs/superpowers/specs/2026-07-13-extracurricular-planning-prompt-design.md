# 课外活动规划 Prompt 优化设计

## 目标

在不降低规划 Agent 创造力的前提下，优化 `prompts/us-college-admissions-strategist-agent.md`，减少虚构成果、资格错配、资源不现实和活动同质化。优化后的 Prompt 保持现有章节顺序、15 项活动要求、表格列、叙事解读结构和整体篇幅量级。

## 保持不变

- 保留从 `# Role` 到 `## 优化说明` 的全部一级、二级和三级章节及其顺序。
- 保留 15 项活动、前 10 项核心候选、后 5 项补强/备选的组合。
- 保留表格五列：`序号 | 活动类型（Type） | 活动名称（精准描述） | 具体执行描述（需含：问题/成果/影响） | 建议年级`。
- 保留表格后的 `### 【活动叙事逻辑解读】`，继续说明 Spike、成长轨迹和录取价值。
- 不修改模型、temperature、max tokens、解析器、前端或生成流程，不增加僵硬的活动模板和评分规则。

## Prompt 调整

1. 将所有建议明确定位为“规划候选”，不得把用户未提供的信息写成已经完成的项目、获奖、发表、成员人数、样本量或准确率。
2. 在现有表格的“具体执行描述”内区分问题、规划动作、目标成果、核验方式；未知数字使用“目标”“建议区间”“待确认”，同时保留原列名和表格格式。
3. 将现有示例中的既成奖项与量化成果改成目标表达，例如“目标申报省级科创赛”“目标采集 1000 条、以测试集评估准确率”，避免示例被模型照抄成事实。
4. 要求涉及竞赛、夏校、实验室、志愿项目和外部合作时，核对或提示核对国籍/身份、地区、年级、申请资格、时间、成本、语言和资源；无法确认时提供可替代路径，不声称资格成立。
5. 强化活动间的递进和依赖：前期探索产生问题与素材，中期研究或组织行动验证方案，后期成果沉淀与社区影响自然延伸；15 项不能只是同一项目换名字。
6. 继续允许 Agent 结合学生兴趣、本地资源和跨学科方向创造活动，不规定固定题材，也不要求每项使用同一种行动方式。

## 篇幅与格式验收

- 优化后字符数控制在原 Prompt 的约 90%–110%。
- 原有章节标题、表格列数、表格后叙事模块和 15 项数量要求全部保留。
- 新 Prompt 明确包含“规划候选”“不得虚构”“目标成果/待核验”“资格与可行性核验”四类语义。
- 示例不再把奖项、发表、人数、样本量或准确率描述为用户已经取得的事实。

## 版本与验证

- 更新 `prompts/manifest.json` 中该 Prompt 的版本、激活引用和 SHA-256。
- 更新 `AI_QUALITY_VERSIONS.deepseekPlanPrompt`，使运行结果记录新的 Prompt 版本。
- 更新 Prompt 完整性测试，覆盖固定结构、真实性边界和新版本标识。
- 运行 `npm run prompt:check`、Prompt/DeepSeek 定向测试和 `npm run verify`；若项目中与本次无关的现有改动导致完整验证失败，单独报告失败项，不改动无关文件。
