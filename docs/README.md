# 项目文档索引

本目录只保留会帮助后续维护、复核产品决策或继续开发的文档。运行时读取的资料库文件不放在这里，位于 `data/`。

## 保留内容

- `superpowers/specs/`：已经确认过的产品、交互与技术设计规格，可用于回溯功能边界与验收口径。
- `superpowers/plans/`：仅保留仍在执行或需要随代码一并审阅的实施计划。功能已落地且规格文档已留存后，过程性计划可删除。
- `../prompts/us-college-admissions-strategist-agent.md`：规划 Agent 使用的固定提示词。
- `../data/*.md`：页面及推荐模块实际读取的业务资料，不属于清理对象。

## 清理规则

- 删除 `.superpowers/` 下的本地头脑风暴预览、浏览器截图、临时数据库和验证脚本产物；这些内容已经由 `.gitignore` 排除。
- 删除根目录运行生成的 `*.log` 文件；发生问题时应重新生成，而不是长期留档。
- 不因“看起来像文档”而删除 `data/` 或 `prompts/` 内容，它们直接参与应用行为。
- 新增功能的过程文档应优先归入 `specs/` 或短期 `plans/`，避免在根目录散落。
